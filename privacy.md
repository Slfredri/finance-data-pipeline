# Privacy Policy – Personal Finance Pipeline

**Last updated:** October 25, 2026

Personal Finance Pipeline is a private, non-commercial application developed exclusively for personal financial analysis.

## Data Collection

The application accesses bank account information and transaction history from the application owner's Handelsbanken accounts through Enable Banking.

## Data Usage

Banking data is used exclusively for personal financial analysis, budgeting, and expense tracking.

## Data Storage

Retrieved financial data is stored locally in a private database controlled by the application owner.

## Data Sharing

Personal Finance Pipeline does not sell, publish, or share banking information with third parties. Enable Banking and Handelsbanken process information as necessary to provide the account connection.

## Data Retention

Financial data is retained for personal analysis and can be deleted by the application owner at any time.

## Contact

For privacy-related inquiries, contact the application owner using the contact email registered with Enable Banking.
